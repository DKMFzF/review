# Зона ответственности

**Кирилл Дорошев (`dkmfzf`) — клиентская часть, инфраструктура**

Разработал Frontend, работал с облаком для развертывания всего приложения.

### Frontend
- Реализовал frontend по архитектурной методологии Feature-Sliced Design: слои `app`, `pages`, `widgets`, `features`, `entities`, `shared`.
- Реализовал Экраны и компоненты для пользовательского сценария:
    - список товаров
    - карточка товара
    - очередь с отображением позиции и прогноза ожидания
    - таймер действия права
    - страница информации о заказе
    - выход из очереди
- Интеграция с прикладным интерфейсом, получение обновлений по Server-Sent Events / WebSocket, управление состоянием на `zustand`, кэширование запросов на TanStack Query.
- Настраивал сборку на `Rsbuild`, статических анализаторов `Biome` и `Steiger`, тестов на `Rstest`.
- Написал `Taskfile.yml` для автоматизации работы с проектом
- Написал документацию по клиентской части (`frontend/README.md`).

### Инфраструктура

- Работал с облаком: автоматизация подготовки сервера (`infra/ansible`).
    - Написла `playbooks/update.yml` для обновление apt-кэша пакетов
    - Написал `playbooks/docker.yml` для установки Docker CE, CLI, containerd и Compose plugin из официального репозитория, запуск и автозапуск службы, добавление пользователя `avito` в группу `docker`
    - Написал `playbooks/htop.yml` для установки `htop`
    - Написал `site.yml` / `run.sh` для оркестрация плейбуков и запуск с параметрами SSH из `.env` (`HOST_IP`, `SSH_USER`, `SSH_PRIVATE_KEY`)
